## Executive summary

Implemented the independent B05 format-schema / generation-contract slice with strict typed contracts for Article, Carousel, and ShortVideo plus a provider/model-neutral generation boundary.

The implementation keeps `audience_contract` separate from `format`, gives each factual content unit a typed source-reference hook, and uses a strict discriminated decoder so an Article payload cannot silently carry carousel slides or video segments. Carousel hard structure is `HOOK -> BODY+ -> CONCLUSION`; short video requires explicit timecodes, visual cues, a hook segment, non-overlapping monotonic timing, and both timeline and estimated spoken duration at or below 60 seconds.

No provider, model, parser, semantic backend, calibrated threshold, or orchestration framework was selected in this slice.

## Findings / implementation evidence

### 1. Typed native-format contracts

Implemented in `src/suno_content/formats/contracts.py`:

- `FormatKind`: `ARTICLE | CAROUSEL | SHORT_VIDEO`;
- `ArticleOutput`, `ArticleSection`, `ArticleParagraph`;
- `CarouselOutput`, `CarouselSlide`, `CarouselRole`;
- `ShortVideoOutput`, `ShortVideoSegment`, `VideoRole`;
- `SourceRef` provenance hook;
- strict `parse_format_output(...)` discriminated decoder;
- `FormatContractError` for structural hard failures.

All models are frozen typed dataclasses with explicit invariants rather than untyped dictionaries.

### 2. Source-ref / provenance hooks per unit

- Article paragraphs carry `source_refs`.
- Carousel slides carry `source_refs`.
- Short-video segments carry `source_refs`.
- `SourceRef` exposes stable integration fields: `source_id`, `anchor_id`, optional `span_id`, `page`, and `claim_id`.

This is intentionally a format-layer hook, not a replacement for the canonical factual/provenance domain produced by W002-T001. T009 should reconcile/map this hook to the accepted T001 source/anchor contracts.

### 3. Carousel hard structural invariants

`CarouselOutput` enforces:

- at least three slides;
- contiguous `slide_index` starting at 1;
- first slide `HOOK`;
- last slide `CONCLUSION`;
- every middle slide `BODY`.

This prevents an arbitrary article/bullet dump from satisfying the carousel contract merely by relabeling the output.

### 4. Short-video hard structural invariants

`ShortVideoOutput` / `ShortVideoSegment` enforce:

- explicit numeric `start_s` / `end_s`;
- finite, valid intervals with `0 <= start_s < end_s`;
- monotonic non-overlapping segments;
- first segment explicitly marked `HOOK`;
- required non-empty `visual_cue` for every segment;
- narration separated from optional on-screen text;
- timeline ends at or before 60 seconds;
- `estimated_spoken_duration_s <= 60`.

The 60-second requirement is frozen because it is briefing-hard; speaking-pace calibration remains outside this slice.

### 5. Article anti-masquerading boundary

`parse_format_output(...)` uses a required `format` discriminator and strict allowed-key sets for every native schema. An `ARTICLE` payload containing `slides` or `segments` fails with `FormatContractError` rather than being silently accepted.

At the generation boundary, a valid Carousel/ShortVideo payload is also rejected when the `GenerationRequest.format` requested `ARTICLE`.

### 6. Audience x format separation

Implemented in `src/suno_content/generation/contracts/models.py`:

- `AudienceLevel`;
- `AudienceContract` with version/rule refs and no format field;
- `GenerationRequest` with independent `audience_contract` and `format` fields;
- `StructuredGenerator` protocol;
- `decode_generation_payload(...)`;
- `validate_output_matches_request(...)`.

No `provider` or `model` field exists in the generation request. Provider/model selection remains an adapter/config concern for a later evidence-driven wave.
