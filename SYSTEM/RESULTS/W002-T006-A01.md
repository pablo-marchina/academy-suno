## Why the harness is semantic-judge independent

The oracle does not decide truth by model consensus. Each fixture freezes source spans, the adversarial output and the expected structured finding. Future deterministic/claim-grounding implementations may use a semantic backend as an additional sensor, but a semantic agreement cannot override a frozen CRITICAL deterministic mismatch. This directly implements the W001-T004/T009 precedence rule.

## Findings / evidence

1. The W001 factual design already supplies a sufficiently concrete deterministic adversarial set to freeze the first EXP-C contract; no semantic threshold is needed for these known mutations.
2. `CRITICAL` needs an absolute FAIL path; material `ERROR` must at least block auto-PASS until repair/re-evaluation or explicit review.
3. Table correctness must be role-aware: value overlap without row/column/unit binding is unsafe.
4. Forward-looking wording requires preserving modality, range/condition and attribution; converting estimate/possibility/guidance into realized fact is a critical corruption.
5. `RETRIEVAL_MISS` and low-confidence extraction must not be collapsed into `UNSUPPORTED`; both require explicit uncertainty/review handling.
6. A positive control is necessary: allowed rounding must pass, otherwise the deterministic layer risks becoming an exact-string checker.
