**Remediation:** lock the invariant “no repository migration without evidence,” not the unevidenced topology. Keep repository topology `PENDING_EVIDENCE` unless a dedicated DRG comparison justifies a winner.

**Recommendation:** T012 should not accept the T010 decision matrix unchanged.

### H-02 — Durable product state ↔ durable event failure consistency is unspecified

**Type:** architectural risk + evidence gap  
**Refs:** `PROD-003`, `PROD-011`, `PROD-013`, `PROD-017`, `RISK-0021`, `RISK-0035`.

T010 correctly separates authoritative product state, durable live events and sampled telemetry, but does not specify transactional/atomic or deterministic reconciliation semantics between a state transition and the durable event representing it.

Crash windows can therefore produce `state committed/event missing` or `event committed/state missing`, causing the cockpit to diverge from product truth despite otherwise correct replay semantics.

**Remediation:** add an explicit state+outbox/event atomicity or deterministic reconciliation contract, then failure-inject partial commits, duplicate delivery, reordering, consumer restart and repair/replay.

**Recommendation:** blocker for freezing PROD-003/011/017 live-event substrate coverage as implementation authority.

### H-03 — Static W004 cockpit “fallback” risks dual product/evidence paths

**Type:** architectural risk + final-evidence ambiguity  
**Refs:** `PROD-005`, `PROD-011`, `PROD-017`, `RISK-0021`, `RISK-0024`, `RISK-0035`.

Keeping W004 static cockpit semantics as a diagnostic/counterfactual is valuable. Treating it as a production/final-evidence “fallback” is incompatible with the single-real-product-path principle if a recipient/final demonstration can silently substitute static/manifests-driven evidence for the live provider/workflow/event path.

**Remediation:** classify the static cockpit as `DIAGNOSTIC_ONLY / COUNTERFACTUAL`, never an automatic production fallback; require final-evidence correlation to current source hash, run/job/event IDs, provider/catalog/policy/evaluator versions and live persistence.

**Recommendation:** blocker for PROD-017 final-evidence acceptance and should be corrected by T012.
