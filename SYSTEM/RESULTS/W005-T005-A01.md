## Key findings / decisions

### 1. Human calibration method — `LOCK`

Default production design is two blind independent primary streams per item plus protocol-triggered adjudication. Agreement is measured before adjudication and retained. More raters can be added for high-uncertainty/high-risk slices, but are not mandated without pilot evidence that their marginal value justifies the cost.

### 2. Sample size — evidence-derived, not hard-coded

Sample size is derived from the estimand plus declared precision/power target using pilot variance/rates. For correlated 3×3 branches, uncertainty is clustered by source document so repeated transformations of the same source are not treated as independent documents.

### 3. LLM/model judge role — `LOCK` as secondary

Model judges may scale semantic/subjective sensing only after calibration against independent human evidence. Known order/verbosity/self-enhancement risks require randomization/swap/stability controls. Judges never override critical hard gates and never become human gold.

### 4. External eval framework — `PENDING_EVIDENCE`

Research covered the existing native Python/pytest baseline plus Promptfoo, DeepEval and LangSmith. All offer useful capabilities, but feature documentation does not establish project superiority. A representative bakeoff is specified before any external framework can be locked. The native typed harness remains the baseline/authoritative semantics boundary meanwhile.

### 5. Threshold promotion — still `DIAGNOSTIC_ONLY`

D-0017 remains historical W004 automated evidence only. Production audience thresholds require independent human calibration and frozen HELD_OUT replication. Framework defaults (including generic LLM-metric thresholds) are not admissible project thresholds.
