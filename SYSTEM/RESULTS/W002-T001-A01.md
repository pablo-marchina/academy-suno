## 3. Implementation

Implemented a strict immutable Pydantic v2 domain foundation under `src/suno_content/domain/**`.

### Core contracts

- `SourceArtifact` and reusable `SourceProvenance`;
- `SourceSpan`, `TableCellProvenance`, `ProvenanceRef`, `BoundingBox`;
- `ParsedDocument` + extraction warnings and child/source lineage consistency validation;
- `Anchor` with typed kind, source trust, materiality and mandatory provenance;
- `VariantSpec` with audience and format kept as independent dimensions plus prompt/output-schema/source/policy references;
- `EvalReport`, `HardGateResults`, `CheckResult`, `Failure`, `RepairInstruction`;
- `ComponentVersions` version spine;
- `RunManifest` with run/attempt/source/version/status/job/output/eval/telemetry references.

### Central enums

Implemented audience, output format, source/content/business context, anchor kind, source trust, materiality, evaluation/gate status, failure severity/category, run status and attempt kind enums.

### Provenance invariants

- source artifacts require source hash and raw artifact reference;
- hashes are normalized to lowercase SHA-256 hex;
- provenance refs must identify either a source span or a complete table cell locator;
- anchors require at least one provenance reference;
- eval reports require at least one source reference;
- failures require at least one evidence reference;
- parsed document children must share the document source identity/hash;
- run output/evaluation refs cannot point to undeclared variant jobs.

### Non-compensatory evaluator invariant

`EvalReport(status=PASS)` is rejected when any hard gate is not `PASS` or when unresolved `CRITICAL`/`ERROR` failures remain. This implements the accepted CRIT-001/HF semantics without introducing numeric thresholds.

### Deterministic serialization

All domain contracts inherit `DomainModel`, which provides:

- strict `extra=forbid` validation;
- immutable/frozen persisted contracts;
- canonical JSON serialization with recursively sorted mapping keys and compact separators;
- explicit `null` fields preserved, including not-yet-selected component versions;
- stable SHA-256 digest over the canonical JSON representation.
